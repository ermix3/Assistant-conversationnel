# Escape Signature Pass
Le Pass est une formule prépayée. Le crédit peut être utilisé sur les services Fitness Lab, kinésithérapie, rituels spa, soins du corps, bien-être et récupération. Les tarifs Pass sont spécifiques à chaque prestation. Les montants et tarifs doivent être consultés dans la base officielle par les outils de prix.
